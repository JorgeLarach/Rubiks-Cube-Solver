This folder contains the main.c and other associated files for a separate STM32 project directory concerned with flashing ~4.5MB of lookup tables used in the Rust solver's heuristic and search algorithms. This is a single-use program, much like the table generation code in cube_solver.

This code is not executable here, it is only included for documentation purposes. If you are interested in more information about this "helper" project, reach out at jorgelarachesp@gmail.com
